# How to Create Your GitHub Profile Banner

## Option 1: Quick Online Tool (Recommended - 5 minutes)

### Using Canva (Free):
1. Go to **https://www.canva.com**
2. Search for "GitHub Banner" or create custom size: **1280 x 640 px**
3. Choose a template or start from scratch
4. **Design Elements to Include:**
   - Your name: "BILEL NASRI"
   - Title: "Data Engineer | AI Engineer"
   - Tagline: "Building Distributed Data Platforms & AI-Powered Applications"
   - Icons: Kafka, Python, AWS, Docker, Spark
   - Background: Dark tech theme (blues, purples, blacks)
   - Optional: Data flow visualization or network nodes
5. Download as PNG
6. Save as `banner.png` in `/home/bilel/Desktop/profile-readme/assets/`

### Using Photopea (Free Photoshop Alternative):
1. Go to **https://www.photopea.com**
2. Create new project: 1280 x 640 px
3. Add text layers and design elements
4. Export as PNG
